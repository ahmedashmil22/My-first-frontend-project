# Frank Originals - Frontend Mini Project

A simple responsive sidebar navigation webpage built using **HTML** and **CSS** only.

## 🚀 Features

- Modern sidebar navigation menu
- Smooth hover effects
- Responsive layout
- Background hero image
- Social media icons section
- Clean and minimal UI design
- Built without JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome (for icons)

## 🎯 What I Learned

While building this project, I practiced:

- HTML page structuring
- CSS positioning
- Flexbox basics
- Sidebar navigation design
- Hover effects and transitions
- Responsive web design concepts

## 🔮 Future Improvements

- Add JavaScript functionality
- Create a mobile hamburger menu
- Add animations for menu opening/closing
- Improve accessibility
- Convert into a fully responsive photography portfolio website

## 📚 About

This is my first frontend mini project created while learning web development. The goal was to practice HTML and CSS fundamentals and understand webpage layout design.
